Perjalanan Belajar Pemrograman Web, Kehidupan Kampus, dan Hobi di Waktu Luang

Ditulis oleh Dimas Prasatya • Dipublikasikan pada 18 Oktober 2026

Halo! Perkenalkan, nama saya Dimas Prasatya dengan NPM 2510010465 dari Kelas 3A NonReguler BJB. Saat ini saya adalah mahasiswa semester 3 yang sedang menempuh pendidikan pada Program Studi S1 Teknik Informatika di Universitas Islam Kalimantan Muhammad Arsyad Al Banjari (UNISKA MAB).

Melalui mata kuliah Pemrograman Web 1, saya sangat bersemangat untuk memahami fondasi utama pembuatan situs web modern. Bagi saya, menguasai penulisan kode HTML5 yang terstruktur secara tepat merupakan pondasi penting sebelum melangkah ke tahap yang lebih lanjut. Dengan menggunakan elemen semantik seperti <header>, <nav>, <main>, <article>, dan <footer>.

Setelah memahami kerangka dasar HTML, tahap perancangan visual menggunakan Cascading Style Sheets (CSS) menjadi bagian yang tidak kalah menarik untuk dieksplorasi. Pada halaman blog ini, saya memadukan palet warna hangat oranye solid (#D98327), krem lembut (#ECE8AF), hijau daun (#4A943E), dan hijau tua (#186049) agar seluruh teks nyaman dibaca.

“Menguasai struktur HTML dan menata tampilan dengan CSS yang bersih adalah langkah awal terbaik sebelum membangun logika aplikasi web yang kompleks dengan JavaScript.”
— Dimas Prasatya, Mahasiswa S1 Teknik Informatika UNISKA MAB

Hobi & Aktivitas di Waktu Luang

Di luar kegiatan akademik perkuliahan, saya senang menghabiskan waktu luang dengan bermain game dan kadang juga mengeksplorasi CSS serta JavaScript secara mandiri. Bermain game membantu saya menyegarkan pikiran sekaligus melatih konsentrasi.

Selain kegiatan di depan layar komputer, saya juga gemar mendengarkan musik santai dan berolahraga ringan agar tubuh tetap bugar.

  • Eksplorasi Web Development: Mempelajari struktur HTML5, penataan layout CSS eksternal, dan logika dasar JavaScript.
  • Bermain Game: Mengisi waktu luang untuk hiburan dan melatih pemikiran strategis setelah kerja :).
  • Mendengarkan Musik Santai: Menemani suasana belajar coding agar lebih tenang dan fokus.
  • Berolahraga Ringan: Menjaga kebugaran fisik di pagi atau sore hari agar tetap sehat selama mengikuti perkuliahan.
